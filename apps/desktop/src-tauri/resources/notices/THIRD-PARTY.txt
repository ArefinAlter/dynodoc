Where the PostgreSQL programs come from
  The binaries are the embedded PostgreSQL 16.15 builds of the zonky.io "embedded-postgres-binaries"
  project (Apache License 2.0 for the packaging), taken from Maven Central and checked against the
  SHA-256 published there (scripts/prepare-pg.mjs). They load these libraries, which sit beside them:
    ICU (icu*.dll)                  the Unicode License
    OpenSSL 3 (libcrypto, libssl)   Apache License 2.0
    libxml2                         MIT licence
    zlib                            the zlib licence
    Zstandard (libzstd)             BSD licence (also offered under GPL v2; used under the BSD)
    LZ4 (liblz4)                    BSD 2-Clause licence
    GNU libiconv and libintl        GNU LGPL 2.1 or later; loaded as separate DLLs, which you may replace
    winpthreads (MinGW-w64)         permissive (MIT-style)
  On Windows the Microsoft Visual C++ runtime (vcruntime140.dll, vcruntime140_1.dll, msvcp140.dll)
  is redistributed as Microsoft permits for the runtime of applications built with Visual C++.

The Dynodoc engine (engine-api, engine-cli) and the Office codec are Dynodoc's own code with the
open-source Rust and JavaScript libraries listed in Cargo.lock and package-lock.json of the
repository, under their own licences.
