Try the working theory.

Every action below is wired to real state. Try to break it. The data model is shared across all four modes; edits anywhere round-trip everywhere.

  1. 1Click any question to select it. The Inspector on the right updates with that item's properties — edit a choice, watch the document update.
  2. 2Right-click any question for the agent menu. Pick "Review for clarity" or "Translate to Bangla" — the agent generates a real suggestion that appears inline.
  3. 3Toggle "Editing" → "Suggesting" in the toolbar. Now edit a question's text directly: it becomes a suggestion attributed to you.
  4. 4Click the comment icon in the gutter (visible on hover). Type a comment, or use @agent to ask the methodologist.
  5. 5Switch modes in the toolbar. Outline lets you navigate. Spec is the live xlsform. Preview shows what the respondent sees.
  6. 6Click the conflict icon in the toolbar to walk through the four-card conflict resolution flow.
